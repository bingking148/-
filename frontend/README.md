# EasyDS Frontend

Vite + React 19 + TypeScript frontend for the EasyDS project.

## Scripts

```bash
npm install
npm start
```

`npm start` and `npm run dev` both launch the dev server at `http://127.0.0.1:3000`.

```bash
npm run build
```

Production assets are emitted to `build/`.

```bash
npm run lint
npm run preview
```

API requests to `/api` are proxied to the Django backend at `http://127.0.0.1:8000`.
